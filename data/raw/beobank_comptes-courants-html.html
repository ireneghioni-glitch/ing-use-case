Questions fréquentes

Qu'est-ce qu'un compte bancaire ?

Un compte bancaire est un compte financier que vous pouvez ouvrir auprès d'une banque pour conserver et gérer votre argent en toute sécurité. Il existe différents types de comptes bancaires, tels que les comptes de paiement et les comptes d'épargne, chacun ayant des fonctions et des objectifs spécifiques.

  • Compte de paiement : Ce type de compte est idéal pour les transactions financières quotidiennes, telles que la réception du salaire, le paiement des factures et les achats. Vous recevez généralement une carte de débit qui vous permet de retirer de l'argent aux distributeurs automatiques et de payer dans les magasins.
  • Compte d'épargne : Ce type de compte permet de mettre de l'argent de côté et d'épargner pour des projets. Il n'est pas adapté aux transactions quotidiennes et offre un taux d'intérêt.

Vous pouvez facilement gérer votre compte bancaire en ligne et sur mobile via la banque en ligne ou l'application bancaire. 

Quels sont les différents types de comptes courants ?

Il existe différents types de comptes courants, chacun étant conçu pour répondre à des besoins et à des habitudes d'utilisation spécifiques. Beobank propose trois types de comptes courants :

  1. Le compte à vue gratuit (compte à vue de base)
    Le compte à vue Go, le compte à vue gratuit, a été spécialement conçu pour la gestion quotidienne de votre argent en ligne. Il est idéal pour les versements de salaire, les paiements et les retraits d'argent. Ce compte comprend une carte de débit gratuite, des paiements sans contact, des services bancaires en ligne et mobiles, des virements automatiques, des transactions électroniques illimitées...
  2. Compte à vue Plus
    Le compte à vue Plus est idéal pour ceux qui utilisent activement leur compte bancaire. Moyennant une cotisation mensuelle de 4 euros, vous profitez de nombreux avantages. Vous bénéficiez de deux cartes de débit et d'un nombre illimité de transactions, tant par voie électronique que dans les agences Beobank, ainsi que de toutes les fonctions de base également disponibles sur le compte à vue gratuit. Avec ce compte à vue multiservices, vous pouvez également recevoir jusqu'à 40 euros de remboursement par an*.
    * Sous réserve de remplir un certain nombre de conditions.
  3. Compte à vue jeunes
    Le compte jeune gratuit, le compte à vue Jump, est idéal pour les jeunes de 10 à 26 ans. Vous y bénéficiez de toutes les fonctions de base, également disponibles sur le compte à vue Go : carte de débit Bancontact/Debit Mastercard, paiements sans contact, utilisation de Payconiq by Bancontact, gestion en ligne, retraits d'argent ...
Pour qui puis-je ouvrir un compte à vue ?

Vous pouvez ouvrir un compte bancaire pour vous-même, pour votre enfant mineur et pour la personne dont vous êtes le curateur.

Combien de comptes à vue peut-on avoir ?

En Belgique, vous avez généralement le droit d'avoir plusieurs comptes à vue dans différentes banques. Légalement, il n'y a pas de nombre maximum de comptes à vue. Toutefois, le nombre de comptes à vue que vous pouvez ouvrir peut dépendre des conditions fixées par les différentes banques. Certaines banques peuvent limiter le nombre de comptes gratuits que vous pouvez ouvrir, tandis que d'autres peuvent facturer des frais supplémentaires pour l'ouverture de plusieurs comptes. 

Comment fonctionne le paiement sans contact ?

Approchez votre carte bancaire du logo sans contact sur le terminal de paiement du commerçant pour régler votre achat. Après plusieurs transactions sans contact consécutives, le terminal de paiement peut vous demander de saisir votre carte et votre code secret pour des raisons de sécurité.

Le paiement sans contact est-il sûr ?

Oui, les paiements sans contact sont sûrs. Les paiements sans contact sont traités de la même manière sécurisée que les paiements ordinaires. Si vous avez signalé la perte ou le vol de votre carte, les transactions sans contact, comme les autres transactions, seront refusées.

Puis-je choisir moi-même le code secret de ma nouvelle carte ?

Oui, pour toutes les nouvelles cartes commandées (cartes de débit, cartes de crédit et cartes Visa Pro à débit différé avec un nouveau numéro).

Nos conseillers Beobank se feront un plaisir de vous renseigner.

Puis-je consulter le code de ma carte bancaire ?

Oui, vous pouvez facilement le consulter vous-même via la fonction 'Digipin' dans Beobank Mobile. Allez dans Comptes > Cartes > sélectionnez votre carte de débit > Code secret.

À quoi dois-je faire attention lorsque je reçois ma nouvelle carte bancaire avec le logo Mastercard ?

La carte Bancontact/Debit Mastercard que vous recevez en remplacement de votre carte avec logo Maestro porte un nouveau numéro de carte*. Votre code PIN reste inchangé.

Votre nouvelle carte contient également un code CVC, une sécurité supplémentaire pour les achats en ligne effectués avec votre carte lorsque vous choisissez de payer avec le logo Mastercard. En outre, votre numéro de carte et sa date d'expiration vous seront souvent demandés. Pour les achats effectués avec Bancontact (via le logo Bancontact), le code CVC n'est pas nécessaire.

*Le numéro de carte est le numéro propre à la carte elle-même. Ce numéro peut parfois être demandé à des fins de vérification, par exemple lors d'achats sur Internet. 

J'ai reçu un SMS de Beobank. Ce message est-il fiable ?

Si vous venez de commander une nouvelle carte ou de faire remplacer votre carte perdue ou volée, il l'est. Chez Beobank, vous pouvez composer le code PIN de votre nouvelle carte Beobank via votre téléphone portable grâce à notre service téléphonique sécurisé.

Puis-je payer à l'étranger avec ma carte de débit ?

Grâce à la carte de débit liée à votre compte à vue, vous pouvez également accéder au réseau international de paiement et de distributeurs automatiques de billets à l'étranger1. 

1Hormis Iran, État de la Syrie, Corée (Nord) et la Russie.

Puis-je utiliser les virements instantanés ?

Les virements instantanés1 vous permettent d'effectuer des virements en Belgique en 5 secondes2. L'argent est immédiatement sur le compte de votre bénéficiaire, même s'il a un compte dans une autre banque3.

Pourquoi utiliser cette fonction ? Payer in extremis une facture oubliée et urgente, rembourser immédiatement un ami, régler un achat urgent...

Comment faire ? Lors de la saisie de votre virement externe dans Beobank Online, il suffit de cocher la case « Instantané »3.

1Service disponible 24h/24, 7j/7 et 365 (ou 366) jours par an.

2La case apparaît si le virement et le bénéficiaire sont éligibles à un virement instantané.

3Sous réserve que la banque du bénéficiaire propose cette option.

Qu'est-ce que la vérification du nom du bénéficiaire ?

La vérification du nom du bénéficiaire, ou Verification of Payee (VoP), est le processus qui consiste à vérifier que le nom de la personne ou de l'organisation qui reçoit un paiement est correct et légitime. Cela permet de s'assurer que le paiement est bien destiné au bon destinataire et de réduire le risque de fraude. Lors de la vérification, le nom et les autres informations du bénéficiaire sont comparés aux informations enregistrées.

Comment fonctionne la vérification du nom du bénéficiaire ?
  • Lorsque vous effectuez un virement, Beobank vérifie automatiquement si le numéro de compte (IBAN) et le nom du bénéficiaire que vous avez indiqués correspondent bien.
  • Si le nom et le numéro de compte ne correspondent pas (entièrement), vous recevez un message.
  • Ce message n'est pas bloquant, vous pouvez toujours effectuer le virement sans apporter de modification. Vous restez donc, comme c'est déjà le cas aujourd'hui, responsable des virements que vous effectuez.
Quels messages / résultats pouvez-vous recevoir lors de la vérification du nom du bénéficiaire ?

Lors de la saisie d'un virement ou ordre permanent, Beobank vérifie automatiquement si le numéro de compte (IBAN) et le nom du bénéficiaire saisis correspondent bien.

Il existe quatre réponses possibles :  

  1. Correspondance parfaite : le nom associé à l'IBAN correspond au nom du bénéficiaire indiqué. Aucune action n'est nécessaire.
  2. Correspondance partielle (*) : le nom associé à l'IBAN ne correspond pas exactement au nom du bénéficiaire indiqué. Le nom du titulaire du compte enregistré auprès de la banque du bénéficiaire s'affiche et vous pouvez le modifier. 
  3. Pas de correspondance (*) : le nom associé à l'IBAN ne correspond pas au nom du bénéficiaire indiqué. Si vous choisissez d'effectuer le virement sans rien modifier, le montant risque d'être versé au mauvais bénéficiaire.
  4. Vérification impossible : impossible de vérifier la correspondance entre l'IBAN et le nom du bénéficiaire indiqué (problème technique). Effectuez le virement à un moment ultérieur.

(*) Si le nom saisi ne correspond pas au nom du bénéficiaire, vous devez confirmer que vous avez pris connaissance de l'avertissement et des risques de fraude, et que vous décidez néanmoins de confirmer le virement.
 

Conseils pour éviter les messages d'erreur à l'avenir :

  • Vérifiez votre liste de bénéficiaires et, si nécessaire, modifiez le nom correct et complet de vos bénéficiaires.
  • Si vous le souhaitez, ajoutez un alias.

Exemple : un compte créé avec le nom du bénéficiaire « Maman » doit être mis à jour avec le nom complet de la personne et l'alias « Maman ».

À quels types de paiements s'applique la vérification du nom du bénéficiaire ?

Tous les virements ou ordres permanents que vous saisissez vous-même et qui sont exécutés en euros, quel que soit le canal utilisé (Beobank Online, Beobank Mobile, Beobank Selfbanking, etc.) vers des comptes auprès de banques de la zone euro (pour autant que la vérification du nom de bénéficiaire soit activée dans le pays concerné).

Elle ne s'applique pas :

  1. Aux paiements dans d'autres devises ;
  2. Aux paiements effectués avec votre carte de débit ;
  3. Lorsque vous ne saisissez pas vous-même le numéro de compte et le nom du bénéficiaire, par exemple lorsque vous scannez un code QR via Payconiq ;
  4. Aux domiciliations.
